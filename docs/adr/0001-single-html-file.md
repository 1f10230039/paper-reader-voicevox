# 0001. 単一の HTML ファイルで作り、依存を持たない

- Status: Accepted

## Context

論文の翻訳テキストを読み上げる、自分のための道具。使うのは「読みたいとき」だけで、
そのたびに開発環境を立ち上げたくない。数年後に別の PC でも同じように動いてほしい。

## Decision Drivers

- 開くまでの手数（ダブルクリックで済むか）
- 数年放置しても動くか
- 中で何をしているかを全部読めること（VOICEVOX のユーザー辞書を書き換える道具なので）

## Considered Options

1. **`reader.html` 1 ファイル** — HTML・CSS・JS を 1 つに収め、`file://` で開く
2. Electron などでデスクトップアプリにする — 配布しやすいが、依存が数百 MB になり更新が要る
3. Node のローカルサーバー＋フロントエンド — 構成は整うが、起動の手数が増える

## Decision

オプション 1 を採用する。UI・整形・分割・英単語の判定・再生・辞書の操作をすべて 1 ファイルに書く。
音声合成は外部の VOICEVOX ENGINE に任せ（→ [ADR-0002](0002-voicevox-with-web-speech-fallback.md)）、
ページ自身は静的なファイルのままにする。

## Consequences

- (+) ブラウザで開くだけで動く。ビルドも `npm install` も無い
- (+) 1,200 行ほどのファイル 1 つなので、全部読める
- (−) ファイルが大きくなるほど見通しが悪くなる。機能を足すときは節ごとのコメントで区切る
- (−) `file://` 起因の制約（CORS）を別途解く必要がある（→ [ADR-0006](0006-allow-origin-null.md)）
