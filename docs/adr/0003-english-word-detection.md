# 0003. 読めない英単語は「1 文字読みの並び」で検出して辞書に登録する

- Status: Accepted

## Context

VOICEVOX は一般的な英単語は読めるが、辞書に無い専門用語（`transformer`、`tokenizer` など）は
アルファベットを 1 文字ずつ読む。論文はこうした語だらけなので、聞くに堪えない。
ユーザー辞書 API で読みを登録できるが、手で全部登録するのは現実的でない。

## Decision Drivers

- 手作業なしで大半の語が聞ける読みになること
- 正しく読めている語を壊さないこと
- 頭字語（`AI` `GPU`）は 1 文字読みが正しいので、そこは触らないこと

## Considered Options

1. **エンジンが返す読みを見て「1 文字読みの並び」なら登録する**
2. 英単語をすべて登録する — 正しく読めている語まで規則変換の読みで上書きしてしまう
3. 自前の英語辞書を同梱する — 網羅は不可能で、ファイルも大きくなる

## Decision

オプション 1 を採用する。読み込み時に本文の英単語を集め、`/audio_query` の `kana` だけを見て判定する。

判定は**完全一致にしない**。`z` が「ゼット」にも「ズィイ」にもなるなど、文字によって読みが揺れるため。
「各文字の 1 文字読みが順番に現れる」割合が 8 割以上で、かつ読み全体が
1 文字あたり 2 カナ以上に膨らんでいれば、読めていないとみなす。

登録する読みは、内蔵辞書（論文頻出の語）にあればそれ、無ければ綴りからの規則変換で作る。
全部大文字 2〜5 文字は頭字語として除外する（内蔵辞書にある語は除外しない）。

## Consequences

- (+) 貼り付けて読み込むだけで、大半の専門用語が聞ける読みになる
- (+) 正しく読めている語には触らない
- (−) 規則変換の読みは完全ではない。右クリックでその場で直せる導線を用意して補う
- (−) 登録先は VOICEVOX のユーザー辞書なので、他の VOICEVOX アプリにも影響する
