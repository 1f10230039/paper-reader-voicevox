# 0005. ランチャーは Edge の専用プロファイル＋ --app モードで開く

- Status: Accepted

## Context

Windows で「ダブルクリックしたら読める状態になる」ようにしたい。
そのためには VOICEVOX ENGINE の起動と、ページを開く操作と、終わったらエンジンを止める操作を
1 つにまとめる必要がある。

## Decision Drivers

- ウィンドウを閉じたら、自分が起動したエンジンを確実に止めること（常駐させない）
- もともと動いていたエンジンは止めないこと
- タブやアドレスバーの無い、アプリらしい窓で開くこと

## Considered Options

1. **Edge を専用プロファイル（`%LOCALAPPDATA%\yomiage-edge`）の `--app` モードで起動し、そのプロセスの終了を待つ**
2. 既定のブラウザで開く — 既存のブラウザに吸収され、ウィンドウを閉じてもプロセスが終わらない。
   ページが閉じられたことをランチャーが知る手段が無い
3. ページ側から `beforeunload` でエンジンに停止を頼む — エンジンに停止 API が無く、
   ブラウザのクラッシュ時に取り残される

## Decision

オプション 1 を採用する。プロファイルを分けることで、ランチャーが起動した Edge は独立したプロセスになり、
`Wait-Process` で終了を待てる。`--disable-background-mode` も付けて、閉じたら確実にプロセスが終わるようにする。

エンジンは `/version` に応答が無いときだけ起動し、その PID を覚えておく。
ウィンドウが閉じたら、覚えている PID の子プロセスごと止める。もともと動いていたものには触らない。

## Consequences

- (+) ダブルクリック 1 回で、エンジンの起動から専用ウィンドウの表示まで済む
- (+) 閉じればエンジンも止まり、常駐しない
- (−) Windows 専用。他の OS ではブラウザで `reader.html` を開き、エンジンは自分で起動する
- (−) 専用プロファイルなので、既定のブラウザの拡張機能や設定は効かない
