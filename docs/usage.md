# 使い方

## 起動する

### ブラウザで開くだけ（どの OS でも）

`reader.html` をブラウザで開く。VOICEVOX ENGINE が `http://127.0.0.1:50021` で動いていれば
自動でつながり、動いていなければブラウザ内蔵の音声（Web Speech API）で読み上げる。

VOICEVOX を使うときは、エンジンを **`--allow_origin null`** 付きで起動しておく。
`file://` から開いたページの origin は `null` なので、これが無いと CORS で弾かれる
（→ [ADR-0006](adr/0006-allow-origin-null.md)）。

```
run.exe --host 127.0.0.1 --port 50021 --allow_origin null
```

### Windows のランチャー

`launch.vbs` をダブルクリックする。コンソールを出さずに `launch.ps1` が走り、次の順に動く。

1. VOICEVOX ENGINE を探す（`../vv-engine/run.exe` → VOICEVOX 本体のインストール先）。
   `/version` に応答が無ければ、裏で起動する（既に動いていれば触らない）
2. Edge を **専用プロファイル**（`%LOCALAPPDATA%\yomiage-edge`）の `--app` モードで開く。
   タブやアドレスバーの無い 420×640 のウィンドウになる
3. エンジンの準備ができたら「あ」を一度合成して、初回の待ち時間を消す（ウォームアップ）
4. ウィンドウが閉じられるのを待つ
5. **自分が起動したエンジンだけ**を子プロセスごと止める。もともと動いていたものは止めない

動作の記録は同じフォルダの `launch.log` に残る（起動しないときはここを見る）。

ショートカットを作るなら `launch.vbs` を対象にし、アイコンに `icon.ico` を指定する。

## 読み上げる

1. 左上の ✎ でテキスト欄を開き、論文のテキストを貼り付ける
2. **読み込んで再生** を押す

貼り付けたテキストは「整形」がオンなら次のように整えられる（PDF からのコピー向け）。

- 文の途中で切れている改行を繋ぐ（空行は段落として残す）
- 英単語の行末ハイフン分断（`trans-` + `former`）を繋ぐ
- ページ番号だけの行を捨てる
- `[12]` `[3, 4]` のような引用番号を落とす

読み込むと文ごとに区切られ、読んでいる文がハイライトされる。
**文をクリックするとそこから再生**。長い文は 90 文字を目安に読点で分けられる。

読み込んだ時点で英単語の走査が走り、読めない語がカタカナ化されて辞書に登録される
（VOICEVOX につながっているときだけ）。

## キー操作

| キー | 動き |
|---|---|
| `Space` | 再生 / 一時停止 |
| `←` `→` | 前の文 / 次の文 |
| `Shift` + `←` `→` | 速度を 0.1 下げる / 上げる |
| `Esc` | 停止（読みの編集バーが開いていれば、それを閉じる） |

速度は上のバーのスライダーでも変えられる。数字を押すと 1.0x に戻る。

## 英単語の読みを直す

VOICEVOX は一般的な英単語は読めるが、辞書に無い専門用語はアルファベット 1 文字ずつ読む。
読み込み時の自動登録で大半は片付くが、気に入らない読みは次の方法で直せる。

- **本文中の英単語を右クリック** → 読みの編集バーが出る。カタカナで入力して保存。
  未登録の語には変換規則で作った候補が入っている
- 設定パネルの「英単語の読み」に登録済みの一覧が出る。ここから削除・追加もできる

登録先は VOICEVOX ENGINE のユーザー辞書なので、このアプリを閉じても残る。
他の VOICEVOX アプリにも効く。

自動登録の対象にならないもの：

- 全部大文字 2〜5 文字（`AI` `GPU` `SNS`）— 頭字語として 1 文字読みのまま残す。
  ただし内蔵辞書にある語（`GPT` `LLM` など）は登録する
- 3 文字未満の語
- エンジンがすでに正しく読めている語

## 設定パネル（右上の ⚙）

| 項目 | 内容 |
|---|---|
| 音声 | VOICEVOX の話者（ずんだもんが先頭）と、ブラウザ内蔵の日本語音声 |
| VOICEVOX | 接続状態。未接続なら理由が出る。選んでいる話者のクレジット表記（`VOICEVOX:話者名`）もここに出る。話者ごとに規約が違うので、公開する音声にはその話者の規約に従うこと |
| 英単語の読み | 登録済みの一覧と追加 |
| 読み上げ速度 | 0.5x〜2.5x |
| 文字サイズ | 12〜24px |
| テーマ | ダーク / ライト |

テキスト・再生位置・速度・話者・文字サイズ・テーマは `localStorage` に保存され、
次に開いたときに続きから始まる。

## 最前面の小窓（⧉）

Document Picture-in-Picture でアプリ本体を小窓に移す。他のウィンドウの上に常に出るので、
PDF を眺めながら再生位置を追える。**元のタブを閉じると小窓も閉じる**ので、開いたままにしておく。
対応ブラウザは Chromium 系（Chrome / Edge）。

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 「未接続」のまま | エンジンが `--allow_origin null` で起動しているか。`http://127.0.0.1:50021/version` が開くか |
| ランチャーで何も起きない | `launch.log`。Edge かエンジンが見つかっていない |
| 英単語が 1 文字ずつ読まれる | 右クリックで読みを登録する。内蔵辞書に足すなら `reader.html` の `BUILTIN` |
| 再生が途中で止まる | ブラウザ内蔵音声の既知の癖。VOICEVOX を使うか、文の分割で回避している |
